# API Reference

The API reference is generated automatically by DocFX from the public APIs and XML documentation comments in the source projects.

## Core and SQL

Includes the public API from:

- `StswExpress.Commons`
- `StswExpress.Sql`

Use the **Core & SQL API** entry in the navigation to browse namespaces, types, methods, properties, and extension methods.

## WPF

Includes the public API from:

- `StswExpress.Wpf`
- `StswExpress.Wpf.Themes`

Use the **WPF API** entry in the navigation to browse controls, helpers, settings, themes, and related WPF types.

> The analyzer package is intentionally not included in the generated API reference because its public Roslyn implementation types are not part of the normal application-facing StswExpress API.
