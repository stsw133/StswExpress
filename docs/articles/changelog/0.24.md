# 0.24.0

**Release Date**: 2026-07-06

## StswExpress.Commons

### Additions

- Added an option to disable log archiving completely.
- Added `SafeSubstring` extension method for safe substring extraction with support for negative indexes and lengths.
- Added `StswLogTarget` flags for controlling where log entries are written, including file, Event Viewer, message box, and custom logging.

### Changes

- `StswExpress.Commons` now targets both `.NET 8.0` and `.NET Standard 2.0`.
- `GetPropertyValue` now supports nested property paths separated by dots or slashes.
- Moved SQL utilities and mail utilities into separate projects/packages.
- Refactored `StswLog` archive handling by moving archive-related logic to `StswLogArchiving`.
- Refactored `StswSettings` loading logic, including sync/async loading improvements and moving `StswSettingsModel`.
- Removed dedicated SQL logging from `StswLog` in favor of generic custom logging.
- Updated NuGet package references and project/package metadata.

### Fixes

- Improved robustness of substring extraction by preventing exceptions when requested ranges exceed string bounds.

## StswExpress.Mail

### Additions

- Added a separate `StswExpress.Mail` project/package for MailKit-based email utilities.

### Changes

- Mail utilities were split out from the shared/common package for cleaner dependency separation.
- Updated `MailKit` package version.

## StswExpress.Sql

### Additions

- Added a separate `StswExpress.Sql` project/package for SQL database utilities.

### Changes

- SQL utilities were split out from the shared/common package for cleaner dependency separation.
- Updated `Microsoft.Data.SqlClient` package version.

## StswExpress.Wpf

### Additions

- Added a pinnable hover-expand controls panel and context menu to `StswMediaPlayer`.
- Added `ClearFilterOnDropDownOpen` property to `StswComboBox` and `StswSelectionBox`.
- Added `MouseWheelBubble` attached property to `StswScrollView`.
- Added `StswEmojiText` control for emoji-rendering text content.
- Added `StswHighlightText` control for highlighting substrings inside `TextBlock` content, including plain text and inline content.
- Added `StswHoldButton` control for hold-to-trigger button interactions.

### Changes

- Improved filtering and focus logic in `StswComboBox` and `StswSelectionBox`.
- Improved icon scaling logic.
- Improved language selection UI with emoji flags and metadata-driven display names.
- Refactored `StswDataGridFilterBox` filter update logic into a centralized `RefreshFilter()` method.
- Refactored `StswNotifyIcon` by removing `ContextControl` and improving context menu binding and window initialization.
- Refactored translation system to support custom languages and fallback behavior.
- Renamed `IStswSelectionItem` to `IStswSelectableItem` and `StswSelectionItem` to `StswSelectableItem` throughout controls, tests, and documentation.
- Split WPF theme resources into a separate project/package.
- `StswDataGrid` now applies filtering through `Items.Filter` and `Items.Refresh` when supported.
- `StswDataGridFilterBox` now handles both collection-view and SQL filter updates in a single refresh path, including SQL parameter sanitization and length limits.
- Updated `StswDataGrid` filtering to use the `DataGrid.Items` property instead of `CollectionViewSource.GetDefaultView`.

### Fixes

- Added a placeholder path for unsupported DataGrid filtering scenarios.
- Improved DataGrid filtering consistency when filter-related properties change.
- Improved `StswNotifyIcon` context handling and initialization behavior.
