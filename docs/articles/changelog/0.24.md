# 0.24.0

**Release Date**: 2026-07-06

## StswExpress.Analyzers

### Additions

- Added the `TryCatch` property to `StswCommandAttribute`. When it is not `StswLogTarget.None`, `StswCommandGenerator` wraps command execution in `try`/`catch` and passes exceptions to `StswLog.WriteException` with the configured target flags.

## StswExpress.Commons

### Additions

- Added `StswLogConfig.Archive.IsArchivingDisabled`; `StswLogArchiving` checks it before initializing or running automatic, manual, size-based, and cleanup operations.
- Added `SafeSubstring`, which supports negative indexes and lengths and returns an empty string when the computed range is invalid or outside the source string.
- Added the `StswLogTarget` flags `File`, `EventViewer`, `MessageDialog`, and `Custom`, used by `StswLog` to select output targets globally or per call.

### Changes

- `StswExpress.Commons` now targets both `.NET 8.0` and `.NET Standard 2.0`.
- `GetPropertyValue` now supports nested property paths separated by dots or slashes.
- Moved SQL utilities from `StswExpress.Commons` into the separate `StswExpress.Sql` project/package while retaining the `StswExpress.Commons` namespace.
- Replaced the MailKit/MimeKit-based implementation in `StswMailboxModel` with `StswSmtpClient` and internal MIME helpers; the MailKit package reference was removed.
- Moved archive-related logic from `StswLog` into `StswLogArchiving`.
- Replaced the dedicated `SqlLogger`/`IsSqlLoggingDisabled` path with the generic `Custom` target and `CustomLogger` callback.

## StswExpress.Sql

### Additions

- Added `GetOpenedAsync`, `OpenedConnectionAsync`, `BulkInsertAsync`, `ExecuteNonQueryAsync`, `ExecuteReaderAsync`, `ExecuteScalarAsync`, `ExecuteStoredProcedureAsync`, and `GetAsync` database helpers with `CancellationToken` parameters.
- Added a separate `StswExpress.Sql` project/package for SQL database utilities.

### Changes

- Updated `Microsoft.Data.SqlClient` from version `6.1.2` to `7.0.1`.

## StswExpress.Wpf

### Additions

- Added a pinnable hover-expand controls panel and context menu to `StswMediaPlayer`.
- Added `ClearFilterOnDropDownOpen` property to `StswComboBox` and `StswSelectionBox`.
- Added `StswSettingsModel.EmojiFontFamily` and `StswEmojiText.EmojiFontFamily` for selecting the local color emoji font.
- Added `MouseWheelBubble` attached property to `StswScrollView`.
- Added `StswEmojiText`, a `TextBlock`-derived control for rendering text containing color emoji.
- Added `StswHighlightText`, which highlights matching substrings in either the `Text` value or authored `Inline` content.
- Added `StswHoldButton`, which invokes its click event and command only after the left mouse button is held for `HoldDuration`.
- Added the abstract `StswInputBoxBase` control and `StswInputBoxBaseAutomationPeer`.

### Changes

- Replaced the generated `System.Configuration` settings with the JSON-backed `StswSettingsModel`; WPF startup loads it synchronously through `StswSettings.Load`, while `LoadAsync` and `SaveAsync` remain available internally.
- Changed `StswIcon` from a templated `Control` to a directly rendered `FrameworkElement`; its nullable `Scale` now clears explicit dimensions when unset and supports auto sizing for star values.
- Added `_language` metadata with emoji flags to the built-in translation files and used it to build language display names.
- Changed `StswColorBox`, `StswDatePicker`, `StswNumberBoxBase`, `StswPasswordBox`, `StswTextBox`, `StswTimePicker`, and `StswPathPicker` to inherit from `StswInputBoxBase`, and removed `StswBoxBase`.
- Centralized `StswDataGridFilterBox` updates in `RefreshFilter()`, which handles both `CollectionView` and SQL modes and sanitizes SQL parameter names to alphanumeric characters with a 126-character limit.
- Removed `StswNotifyIcon.ContextControl`; the control now resolves its window through `Window.GetWindow(this)` or `Application.Current.MainWindow` and synchronizes the context-menu data context from its own `DataContext`.
- Reworked `StswEmojiText` to render emoji locally from installed OpenType color fonts instead of downloading PNG files or using a disk cache. `EmojiSourceTemplate` and `PreserveVariationSelector` remain only as obsolete, ignored compatibility properties.
- Added `StswTranslator.RegisterCustomLanguage` and fallback-language chains for loading and resolving custom translations.
- Renamed `IStswSelectionItem` to `IStswSelectableItem` and `StswSelectionItem` to `StswSelectableItem` throughout controls, tests, and documentation.
- Moved the optional Halloween, Night, Pink, Spring, Summer, and Winter WPF theme resources into the separate `StswExpress.Wpf.Themes` project/package.
- Changed `StswDataGrid` collection filtering from `CollectionViewSource.GetDefaultView(ItemsSource)` to `Items.Filter` and `Items.Refresh` when `Items.CanFilter` is `true`.
